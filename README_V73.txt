LOWIS Zuschnittplaner V73 – GitHub Pages

Dateien im ZIP direkt in das Stammverzeichnis des GitHub-Pages-Repositories hochladen.

Wichtig:
- index.html ersetzt die bisherige Startdatei.
- sw.js wurde auf Cache-Version V73 angehoben, damit alte V72-Dateien nicht dauerhaft aus dem Browser-Cache geladen werden.
- manifest.webmanifest und icon.svg können vorhandene gleichnamige Dateien ersetzen.
- index_v73.html ist nur eine Sicherungskopie derselben V73-Datei.

V73 Änderungen:
1. Platten-Tabs horizontal scrollbar, Maus-Ziehen, Touch-Swipe und Mausrad-Unterstützung.
2. PDF-Schraffur wird exakt auf die Rohplatte geclippt.
3. Einheitlicher PDF-Maßstab für alle Rohplatten desselben Plans.
4. Einheitliche Schriftgröße der sichtbaren Maßzahlen.
5. Positionsnummer mit festem Innenabstand oben links.
6. Kollisionsärmere Beschriftung; kleine Teile werden bei Platzmangel in der Zusatzinfo ausgegeben.
