LOWIS Zuschnittplaner V74 – GitHub Pages

Dateien im ZIP direkt in das Stammverzeichnis des GitHub-Pages-Repositories hochladen.

Wichtig:
- index.html ersetzt die bisherige Startdatei.
- sw.js wurde auf Cache-Version V74 angehoben, damit Browser nicht die alte V73 aus dem Cache anzeigen.
- manifest.webmanifest und icon.svg können vorhandene gleichnamige Dateien ersetzen.
- index_v74.html ist nur eine Sicherungskopie derselben V74-Datei.

V74 Änderungen:
1. PDF-Zuschnittplan: zwei große Platten/Gruppen pro A4-Seite.
2. Neben jeder Platte steht eine eigene Stückliste der auf dieser Platte liegenden Teile.
3. Gleiche Positionen auf einer Platte werden mit Stückzahl zusammengefasst.
4. Die komplette Bezeichnung wird umgebrochen und nicht mit ... abgeschnitten.
5. Die Plattenzeichnung bleibt links groß und einheitlich; die Stückliste steht platzsparend rechts.
6. Alle V73-Korrekturen bleiben erhalten (scrollbare Plattenleiste, geclippte Schraffur, einheitliche Maße, bessere Positionsnummern und Kollisionslogik).
