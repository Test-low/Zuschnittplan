LOWIS Zuschnittplaner V80
===========================

Änderungen gegenüber V79:
- Akzentfarbe im White- und Dark-Mode auf #2F7D3A umgestellt; grelle V79-Verläufe wurden entsprechend abgedunkelt.
- Plattenzuschnitt, Längenzuschnitt und Projektmodus besitzen drei voneinander unabhängige Browser-Entwürfe.
- „Plan leeren“ / „Projekt leeren“ löscht nur den aktuell geöffneten Bereich. Die beiden anderen Entwürfe bleiben unverändert.
- Beim ersten Öffnen eines Bereichs pro Browser-Sitzung erscheint nur für diesen Bereich die Abfrage „Letzten Plan fortsetzen?“ / „Neuer Plan“, sofern dort ein sinnvoller Entwurf gespeichert ist.
- Längenzuschnitt startet mit „Materialauswahl“ ohne Dimensionen oder Rohlängen.
- Projektmodus startet jede neue Position mit „Materialauswahl“ ohne Dimension oder Rohlänge.
- Beim Leeren werden im jeweiligen Bereich Planname/Projektname, Projektbeschreibung, Material-/Maßauswahl, Positionen und Ergebnis zurückgesetzt.
- Vorhandene V79-Längen-/Projektentwürfe werden beim ersten Start automatisch in die getrennten V80-Speicher überführt.
- PDF-Import bleibt erhalten und übernimmt den importierten Plan direkt, ohne dass ein gespeicherter Entwurf darübergelegt wird.
- Alle bisherigen V78/V79-PDF- und Zuschnittfunktionen bleiben erhalten.

GitHub Pages:
Alle Dateien aus diesem ZIP in das Repository kopieren und gleichnamige Dateien ersetzen.
Der Service-Worker-Cache lautet lowis-zuschnittplaner-v80.
