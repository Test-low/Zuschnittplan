LOWIS Zuschnittplaner V90
===========================

Änderungen gegenüber V89:
- PDF im Plattenzuschnitt: Plattengrafiken werden pro Halbseite automatisch so groß wie möglich dargestellt.
- Weiterhin zwei Plattenblöcke pro A4-Seite; die Stückliste bleibt direkt darunter.
- Bei kurzen Stücklisten wächst die Zeichnung bis auf 255 pt Höhe; bei langen Listen wird sie automatisch angepasst.
- Spanplatte roh wurde in Spanplatte roh V20 umbenannt (bestehende Dicken 10/12/16/19 mm, 2800 x 2070 mm).
- Neu: Spanplatte roh V100, 4110 x 2070 mm, 22 mm.
- Neu: Hartfaser weiß, 2800 x 2090 mm, 3 mm.
- Neu: 3-Schicht/ Fichte, 5000 x 2050 mm, 19 mm.
- Alte gespeicherte Pläne/PDFs mit der Bezeichnung "Spanplatte roh" werden beim Laden automatisch auf V20 bzw. bei 4110 x 2070 / 22 mm auf V100 zugeordnet.
- Alle Funktionen aus V89 bleiben erhalten.
